# Huellas_del_conflicto
Proyecto integrador de Ciencia de Datos (UNICAFAM) sobre el Registro Único de Víctimas de Colombia. Tres análisis independientes —series de tiempo interrumpidas, pronóstico del incremento entre cortes y aprendizaje automático— para separar lo que el registro dice del conflicto de lo que dice de su propia inscripción.
